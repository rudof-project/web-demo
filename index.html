rudof online demo
Help Manual npm GitHub

Convert RDF data and property graphs between formats, validate them with ShEx, SHACL, DCTAP or PGSchema, and query RDF data with SPARQL. Everything runs in your browser: rudof is compiled to WebAssembly, and nothing you type is sent anywhere, except the queries to the SPARQL endpoint you give. Loading rudof…
